# Cuaderno AULES · Descargas

Este repositorio distribuye **solo instaladores y manifiestos de actualización**.
El código se mantiene en un repositorio privado. No se incluyen datos de alumnado,
cursos del autor, entregas, notas, programaciones, cookies o credenciales.

## Estado

Primera versión de desarrollo en preparación. Los instaladores aparecerán en
[Releases](https://github.com/sotoliborio/aules-cuaderno-releases/releases) cuando
la compilación y las comprobaciones hayan terminado. Todavía no hay una versión
estable recomendada para uso compartido.

## Funcionamiento

Cuaderno local para actividades AULES, evaluación por RA/CE, rúbricas,
cuestionarios, propuestas de corrección y publicación autorizada por el docente.
Cada profesor conecta con su propia cuenta y guarda sus datos en su ordenador.
La corrección IA necesita Codex CLI instalado y autenticado con la cuenta propia;
consume su cuota. Las propuestas se guardan como borradores para revisión.

## Actualizaciones

Desde el botón de versión de la app: buscar actualizaciones, revisar los cambios,
instalar y reiniciar. Los artefactos de actualización deben tener una firma válida.
Los datos locales permanecen separados del programa. Una actualización espera a
que terminen las correcciones y prepara una copia local del registro.

La firma del mecanismo de actualización es distinta de la firma/notarización del
sistema operativo. Las versiones iniciales pueden mostrar advertencias de Windows
o macOS; consulta las notas de cada release antes de instalar.

Este repositorio no recibe ni almacena datos de AULES.
